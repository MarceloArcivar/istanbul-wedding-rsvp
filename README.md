# Istanbul Wedding RSVP

A personal "can you come?" page for our wedding guests, in Spanish, English and Turkish. Each invitation gets its own link; answers land in a private Google Sheet.

- `CLAUDE.md` — full project brief (decisions, architecture, privacy rules, next steps)
- `design/approved-preview.html` — the approved design, with sample guests (open in a browser)
- `assets/` — skyline illustration and couple photo
- `guests/guests.example.csv` — format of the guest list (the real list never goes in this repo)
